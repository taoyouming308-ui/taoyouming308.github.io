# Salon Core

订单编辑版本见 `../../docs/salon-order-edit-version.md`。`order_lines` 必须携带当前记录读取时的 expectedVersion；未知请求重试冻结原版本，不能在提交前刷新版本掩盖冲突。版本冲突停止当前保存，按编号原单查询仍只读。

`draft-editor.mjs` 提供本机新建/原请求恢复/列表重选草稿的多项目编辑：逐项添加、数量、移除、完整冻结提交；回读/恢复保留全部明细的原价格、优惠和员工归属。只存内存，切店/重连/退出前提示丢弃，身份失效立即清除。没有改价、优惠审批、员工选择或支付入口。

`order-list.mjs` 提供本店订单分页投影与文本安全展示；状态筛选、每页 50 单、查看和显式载入草稿。载入时重新读取状态/版本，不用列表缓存覆盖；离开编辑不删除原单。边界与验收见 `../../docs/salon-order-list.md`。

`order-readback.mjs` 在保存后的回读中逐项匹配完整提交明细，包括重复行数量、项目/服务员工 ID、数量、单价和优惠；顺序不影响匹配。差异只触发保留待核对状态，不视为失败回滚或允许重写。复用订单范围校验，不另行计算服务端总计。

`order-inspection.mjs` 为本机工作台的已知内部编号只读查询投影：检查订单/明细范围，只显示单号、状态、项目及应收；不保存全回执、不显示支付/顾客详情、不绑定旧单到编辑器。不是订单列表、收银或正式 App 接入。

未知结果只读核对见 `../../docs/salon-request-lookup.md`：员工 request_lookup 首批仅支持建档、开单草稿、订单明细回执；不重放业务，不把 unconfirmed 当作失败。本机员工页已接同标签页 sessionStorage 最小元数据清单，刷新后重新验证身份并人工查询；不涵盖关闭标签页、跨设备或顾客端。

三类写入成功回执之后，仍须回读并匹配当前资源才能清除清单。回读失败保留请求号、禁止新业务且关闭写入重试，只允许只读核对；草稿创建和明细保存后的编辑能力使用当前订单状态，不依赖历史回执。

预约时间转换边界见 `../../docs/salon-store-time.md`。`store-time.mjs` 必须显式传入时区，拒绝夏令时不存在或重复时间；工作台从鉴权的 store_time 读取门店时区与版本，不以设备时区替代。三个改期 API 使用事务内时区包装函数，原业务函数只供内部复用；不开放时区修改入口。

独立门店经营系统的领域边界。开发阶段不接入现有员工端、前台或悦西智营，也不写美管加。

第一阶段对象：组织、门店、角色、员工、顾客、项目/商品、预约、订单、会员账户、账户流水、支付和审计。

规则：

- 所有业务数据必须带组织范围；门店业务同时带门店范围。
- 资金、次数、支付和审计只追加，禁止覆盖历史；纠错使用反向流水。
- 订单是预约、到店、服务、收银、业绩和日报的主链。
- 浏览器不直接获得业务表写权限；正式接口统一由后续 `salon-api` 校验会话、角色和门店。
- 本模块通过全部离线测试以前不得迁移生产数据库或接入现有三个板块。

本机接口联调入口和测试边界见 `../../docs/salon-local-api-workbench.md`。`api-client.mjs` 提供显式接口、门店上下文、字段映射与冻结请求重试；目前仅接入独立联调工作台，不代表原 13 模块已经切换到正式接口。

业务请求通过 `request-deadline.mjs` 最多等待 30 秒（包括响应正文）。超时只表示浏览器不再等待，不证明数据库回滚；保留原请求参数和请求号，由用户重试核对，不自动重发。AbortSignal 被传递给 fetch，但忽略信号的传输也受等待上限约束，迟到结果不交给页面。员工客户端与顾客改期页已接入；其他旧 App 不在保护范围内。测试可显式缩短等待，不改变正式默认值。

会话读取、服务端身份验证、退出及两端本机合成登录各有 30 秒等待上限。身份读取/验证失败清除上下文，旧结果不能恢复业务；退出失败或超时保留“退出待确认”锁定，仅手动重试退出成功后允许重新连接。SDK 调用可能在超时后继续执行，不能把停止等待称作撤销成功。测试提供 authTimeoutMs，不改变实际 SDK 方法签名；真实会话和正式登录仍待接入。

`session-controller.mjs` 在统一客户端外增加经过身份验证的 Auth 会话生命周期；只接收显式注入的 Salon 专属 Auth 实例，不自行选项目/登录方式、读取旧 App 会话或分配权限。当前工作台与专项测试使用合成 Auth 替身；真实 SDK、测试项目和端到端登录验收仍待接入。
